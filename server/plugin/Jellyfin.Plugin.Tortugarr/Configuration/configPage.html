Tortugarr

Server side of the Tortugarr app. Keys and passwords are never shown here and never sent to the app: leave a key field empty to keep the saved key.

Connections

qBittorrent: when Radarr has an enabled qBittorrent download client, the plugin follows that address and only the login comes from here.

Download limits

Lets a user who is not an administrator use Download Now and missing episodes within these limits. Files over the size limit are shown greyed in the app; the server refuses a download over a limit. Empty or 0 = no limit. "Used" counts the last 7 days. Administrators are never limited.

Adult library

Off by default. When switched on, a separate library is created on the save path below and hidden from every user who is not an administrator, including users created later. Give a user access in Dashboard > Users > the user > Access. Only administrators can search and download for it. No indexers are added - add your own in Prowlarr. It needs qBittorrent.
