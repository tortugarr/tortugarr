Tortugarr

Server side of the Tortugarr app. The addresses and keys of Sonarr, Radarr, Prowlarr, Bazarr and the download client are set by the Tortugarr installer and are never sent to the app.

Adult library

Off by default. When switched on, a separate library is created on and hidden from every user who is not an administrator, including users created later. Give a user access in Dashboard > Users > the user > Access. Only administrators can search and download for it. No indexers are added - add your own in Prowlarr. It needs qBittorrent as the download client.
